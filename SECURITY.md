# Security Policy

## Supported versions

We support the **latest release** and the current development branch. Versions follow [semantic versioning](https://semver.org/) (MAJOR.MINOR.PATCH).

| Version | Supported |
| ------- | --------- |
| Latest release | Yes |
| Older releases | No |

When a vulnerability is fixed, we ship a new patch release. Please upgrade to the latest release to receive security fixes.

## Reporting a vulnerability

**Do not open a public issue** for security vulnerabilities.

- **Preferred:** Use [GitHub Security Advisories](https://github.com/hrodrig/kzero/security/advisories/new) for a private report.
- **Alternatively:** Contact the maintainer via the profile at [github.com/hrodrig](https://github.com/hrodrig) with a clear description, steps to reproduce, and impact.

We will acknowledge your report as soon as we can, work on a fix, and coordinate disclosure when appropriate.

Thank you for helping keep kzero and its users safe.
